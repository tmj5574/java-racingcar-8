# java-racingcar-precourse

### 1. 개인적인 목표

- TDD(Test Driven Development)를 공부하고 개발 과정에 적용해보자.
- Stream을 활용해보자.

### 2. 기능 구현 사항

**📍입력**

- [ ]  사용자에게 경주할 자동차 이름을 입력 받는다.
    - [ ]  경주할 자동차 이름을 쉼표(,)로 구분한다.
    - [ ]  프로그램에 각 자동차를 저장한다.
    - 각 자동차 이름이 5자를 초과할 경우 → 예외발생(`IllegalArgumentException`)
- [ ]  사용자에게 경주 횟수를 입력 받는다.

**📍게임 진행**

- [ ]  각 자동차마다 랜덤 값을 추출한다. (입력 받은 횟수만큼 반복)
    - [ ]  4 이상인 경우에만 해당 자동차를 전진시킨다.
- [ ]  해당 라운드의 결과를 출력한다.

**📍출력**

- [ ]  우승자를 출력한다.
    - [ ]  여러명일 경우 쉼표를 통해 구분한다.

### 3. Edge Case (경계 입력)

**📍입력**

- 자동차 이름이 주어지지 않은 경우 (”\n” 입력) → 예외발생(`IllegalArgumentException`)
- 횟수가 주어지지 않은 경우 (”\n” 입력) → 예외발생(`IllegalArgumentException`)
- 횟수가 0으로 입력된 경우 → 게임 종료
